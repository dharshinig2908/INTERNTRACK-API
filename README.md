INTERNTRACK-API

Project Description

INTERNTRACK-API is a Node.js API project for managing internship information.

Technologies Used

- Node.js
- Express.js
- SQLite (better-sqlite3)

Installation

1. Install Node.js.
2. Open the project folder in VS Code.
3. Run "npm install".

Run the Project

Run the following command in the terminal:

"node server.js"

API Endpoints

- "GET /" — Check the API welcome response.
- "GET /api/internships" — Retrieve internship records.
- "POST /api/internships" — Create an internship record.

Local Testing

Base URL: http://localhost:3000

Test the internship endpoint at: http://localhost:3000/api/internships


Notes

Run the server locally before testing the endpoints. Refer to the route code for required request fields and any additional endpoints.
